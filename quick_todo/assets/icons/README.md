# 可选图标素材

无需素材即可使用，程序内置蓝色圆角勾选图标，按钮使用文字和系统控件。

如希望更换应用 Logo，将以下任意一个文件放在本目录，重启生效：

| 文件名 | 推荐规格 | 用途 |
| --- | --- | --- |
| `app.ico` | 含 16、32、48、256 像素尺寸 | Windows 窗口和托盘图标，优先读取 |
| `app.png` | 256 × 256，透明背景 | 没有 ICO 时读取 |
| `app.svg` | 正方形 viewBox、自包含 SVG | 没有 ICO/PNG 时读取 |

只需准备其中一个。建议轮廓简单、边缘留白、小尺寸清晰；不需要额外的新增、删除、搜索等图标。
